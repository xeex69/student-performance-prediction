# 🎓 Student Performance Prediction (Machine Learning Project)

## 📌 Project Overview
This project predicts a student's **final grade (G3)** based on academic, personal, and lifestyle factors using **Machine Learning**.

The goal is to understand which factors influence student performance and build a regression model to make accurate predictions.

---

## 📊 Dataset
- Dataset: Student Performance Dataset
- Total Records: 649 students
- Features: 32 input features
- Target Variable: `G3` (Final Grade)

The dataset includes:
- Academic scores (`G1`, `G2`)
- Study habits
- Family background
- Lifestyle attributes

---

## 🧠 Problem Type
- **Supervised Learning**
- **Regression Problem**

---

## ⚙️ Technologies Used
- Python
- Pandas

- Jupyter Notebook

---

## 🛠️ ML Pipeline
1. Data Loading & Exploration  
2. Feature Selection  
3. Categorical Data Encoding  
4. Train-Test Split  
5. Model Training (Linear Regression)  
6. Model Evaluation  
7. Model Saving  

---

## 📈 Model Used
- **Linear Regression**

---

## ✅ Model Performance
- **R² Score:** 0.84  
- **Mean Absolute Error (MAE):** 0.76  

The model predicts final grades with **high accuracy**, with an average error of less than **1 mark**.
